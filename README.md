# Roblox Account Changer Bot

## Как запустить на Railway

### 1. Получи токен бота
- Открой Telegram → @BotFather
- Напиши `/newbot` → дай имя → скопируй токен

### 2. Узнай свой Telegram ID
- Напиши боту @userinfobot
- Скопируй число (твой ID)

### 3. Залей на Railway
1. Зайди на https://railway.app
2. New Project → Deploy from GitHub (или загрузи папку)
3. Добавь переменные окружения:

| Переменная  | Значение           |
|-------------|-------------------|
| BOT_TOKEN   | токен от BotFather |
| OWNER_ID    | твой Telegram ID   |

### 4. Запусти
Railway сам установит зависимости и запустит `python bot.py`

---

## Команды бота
- /start — главное меню
- 🔑 Сменить пароль
- 📧 Сменить почту  
- 🔐 Добавить 2FA (ты вводишь код вручную в боте)
- 🗑 Убрать 2FA
- ⚡ Массовая смена (пароль / почта / пароль+почта)

## Формат массовой смены
```
# Только пароль:
логин:пароль:новый_пароль

# Только почта:
логин:пароль:новая_почта

# Пароль + почта:
логин:пароль:новый_пароль:новая_почта
```
